# 🤖 KAIRA AI Agent

> **⚠️ Project Status:** KAIRA is currently in **active development**. This repository represents the initial phase of the project, and features, architecture, and documentation are subject to change as development progresses.

KAIRA is an AI-powered desktop assistant designed to bridge natural language interaction with real desktop automation. It combines a modern web interface, a Node.js backend, and a Python-based desktop agent to perform intelligent tasks such as system automation, browser control, file management, and AI-assisted workflows.

## ✨ Current Features

* 💬 AI-powered conversational interface
* 🧠 Google Gemini integration
* 🖥️ Desktop automation through a Python agent
* 🌐 Browser automation
* 📂 File and folder management
* 📋 Clipboard operations
* 📸 Screenshot capture
* 🔍 OCR support
* 🔊 System volume control
* ⚡ Modern React + Electron interface

## 🛠️ Tech Stack

| Layer         | Technologies                          |
| ------------- | ------------------------------------- |
| Frontend      | React, TypeScript, Vite, Tailwind CSS |
| Backend       | Node.js, Express                      |
| Desktop Agent | Python, FastAPI                       |
| AI            | Google Gemini                         |
| Desktop       | Electron                              |
